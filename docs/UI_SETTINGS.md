# Сохранение настроек панели

Настройки сохраняются автоматически в локальной базе `results/monetizer/monetizer.sqlite3`, отдельно от параметров и очереди конкретного поиска. Запускать поиск ради сохранения не нужно.

## Что запоминается

- Включение AI, Base URL, Model ID, лимит запросов, общий таймаут и лимит текста в байтах UTF-8.
- Источник поиска, выбранные тематики, специализация, список каналов и цель.
- Страна, язык, тип канала, возраст, ERR/ER, состав аудитории, подписчики, охваты, ИЦ и флаги исключения.
- Критерии публичного аудита, число потоков, частота запросов и бюджет.
- Параметры Dev-режима и ожидания Chrome.
- Фильтры результатов и базы, тон сообщения, последний открытый раздел.
- Профиль отправителя: имя, роль, услуги, опыт и условия — автоматически в существующую запись профиля.

Текстовое поле сохраняется после Enter или выхода из поля. В многострочном поле примените ввод через Ctrl+Enter или переведите фокус. Переключатели, списки и ползунки сохраняются после изменения. Если закрыть браузер до передачи нового значения серверу, последние несданные символы могут не сохраниться.

При первом запуске обновлённой панели настройки восстанавливаются из последнего сохранённого запуска, затем сохраняется последнее выставленное в интерфейсе значение. Пустое поле, снятая галочка и очищенный список тоже являются значениями и не заменяются настройками по умолчанию. Если каталог тематик или допустимый диапазон изменились, несовместимые значения отбрасываются. Ошибка записи показывается предупреждением.

Подтверждения доказательств и бизнес-действия по кандидатам не являются настройками. Рабочие статусы, заметки и утверждённые сообщения используют существующие кнопки сохранения; автоматическое сохранение предпочтений не отправляет сообщений, не запускает поиск и не сбрасывает историю/лимит запросов AI.

## API-ключ

В Windows API-ключ автоматически шифруется через DPAPI для текущего пользователя; в SQLite хранится только шифротекст в отдельной записи. Ключ не попадает в JSON обычных настроек, CSV/Excel, checkpoint, Git и логи. Очистка поля удаляет сохранённую запись. Не показывайте сам ключ и не отправляйте его в чат.

Для переноса на другой компьютер или другого пользователя Windows может потребоваться повторный ввод. В остальных ОС открытый ключ на диск не сохраняется. Для консоли остаётся переменная окружения `MONETIZER_AI_KEY`.

Если старая версия уже закрыта, она не оставляла сохранённого ключа: в новой панели его потребуется ввести один раз. Если поле прежней сессии доступно при обновлении интерфейса, значение сохраняется защищённым способом автоматически.

## Настройки прокси

На скриншоте показана отдельная панель gemini-web2api-go. Кнопка **Save & apply** применяется к настройкам этого прокси. Изменения его аккаунтов, cookie, RPM/RPH, количества одновременных запросов или ключа не передаются автоматически в наш парсер.

После смены API-ключа обновите поле в парсере. Если меняется endpoint или модель, обновите соответствующие поля. Начальный локальный лимит парсера остаётся максимум пять AI-запросов на запуск, один исходящий AI-запрос за раз; серверные лимиты прокси действуют дополнительно.

Автозаполнение восстанавливает данные и предпочтения, но не запускает панель, TGStat или AI-аудит за пользователя.
