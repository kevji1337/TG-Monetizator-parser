## Правила работы

- Пресеты и подготовленный следующий поиск не запускают Chrome сами. Категории текущей задачи остаются зафиксированы. Список исключений применяется к новым поискам и очереди при продолжении; старые записи не удаляются.
- Оценка времени появляется после достаточной выборки. При включённом AI она относится к наполнению очереди кандидатов, а не к гарантированному получению нужного числа экспертов.
- Первичный/глубокий этап выбирается явно. Это выбор модели для текущего запуска, а не два автоматических запроса на каждый канал.
- Эксперименты AI используют исходный run_id и общий лимит пяти POST; ошибки тоже учитываются. Кэш действует отдельно для модели, варианта и контекста. Если остатка хватает лишь на один ответ, второй отмечается как недоступный по бюджету.
- AI-эксперимент работает в отдельном потоке; панель остаётся доступной. В лаборатории есть остановка локального ожидания. Удалённая генерация на прокси может продолжиться после отмены; такой запрос уже учтён в лимите.
- Ответы экспериментов сохраняются отдельно в SQLite и доступны для скачивания. Они не заменяют основной вердикт, рабочий статус или ручное сообщение. Исправление сохраняет все невыбранные поля дословно; изменённые цитаты проходят полную проверку. Изменившиеся исходные тексты требуют нового полного разбора.
- Для сравнения промптов используется один снимок источников. Это сравнение инструкций, не гарантия воспроизводимости модели.
- Анализ выбросов требует минимум пяти известных счётчиков у постов возрастом от 18 часов. Он не доказывает накрутку и автоматически не отклоняет канал. Стабильность тематики требует выбранной специализации/категорий и минимум четырёх текстов без метки пересылки; доля терминов не подтверждает экспертность.
- Для тематического индикатора берутся посты без метки пересылки; отсутствие этой метки само по себе не подтверждает авторство. Проверка личного эксперта остаётся отдельной.
- Для подбора порога нужно минимум 20 актуальных ручных меток и оба класса в обучающей и контрольной частях. Предложение оценивает только активность поста, не заменяет проверку автора и темы. Применяется явно к следующему поиску.
- Экономика — сценарий по введённым числам, фактическая выручка вводится отдельно. Разные валюты не суммируются. Статистика ответов использует историю статусов; договорённости задаются вручную.
- Напоминания в закрытой панели не исполняются. Для уведомлений импортируйте ICS в календарь: контакт назначен на 09:00 местного времени, опережение задаётся при выгрузке.
- Теги, подборки, экономика, пресеты и эксперименты находятся в отдельных таблицах SQLite и не перезаписываются публичными аудитами. Новые поля CSV/Excel добавлены справа.

## Исправление автообновления

Ошибка `PersistentUI.__init__() got an unexpected keyword argument 'disabled'` означала смесь новой страницы и старого модуля в памяти. Теперь перед импортом страницы проверяется поколение исходников. При изменении файлы импортируются заново, а словари модулей работающего обработчика не изменяются. Сам объект фоновой задачи и окна Chrome остаются в реестре процесса. Между задачами создаётся новая версия обработчика.

Дополнительная проверка UI API перечитывает старую версию `PersistentUI` и функций профиля при несовместимой сигнатуре. Для применения исправления достаточно перерисовки страницы; принудительно завершать активный поиск не требуется.
