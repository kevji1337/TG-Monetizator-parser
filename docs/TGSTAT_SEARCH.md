# Поиск по тематикам TGStat

Обновление 16 октября 2026: основной поиск переведён на реальные тематики сайта.

## Как пользоваться

1. Запустите `run_monetizer.bat` вручную или файл «Запуск_Робота_TG.bat» на Рабочем столе.
2. Выберите «TGStat — каталог тематик» и одну или несколько тематик, например «Дизайн», «Психология», «Бизнес и стартапы».
3. При необходимости измените «Фильтры TGStat» и цель по подходящим каналам.
4. Нажмите «Начать поиск и аудит». Если сайт запросит проверку, пройдите её в открытом Chrome.

Текстовый запрос пуст. Для каждой выбранной тематики парсер выставляет её ID в `select#categories` формы TGStat и применяет числовые фильтры. Сбой применения фильтра останавливает эту выдачу; неограниченный поиск не подставляется.

В панели представлены 47 настоящих тематик, 89 стран и 84 языка из сохранённой формы TGStat от 15 октября. Кнопка «Обновить тематики с TGStat» заново читает варианты всех трёх списков в Chrome без запуска поиска. При каждом поиске выбранные значения проверяются по текущей форме сайта. Обычная загрузка панели не открывает Chrome и не обращается к TGStat.

## Начальные фильтры по скриншотам владельца

| Фильтр | Значение |
| --- | --- |
| Ключевое слово | пусто |
| Тематика | выбор пользователя, изначально «Дизайн» |
| Страна | любая |
| Язык | русский |
| Тип канала | любой |
| Возраст | от 12 месяцев, верхняя граница 120+ |
| ERR | от 10%, верхняя граница 100+ |
| ER | без дополнительного ограничения, начальная отметка 0 |
| Мужская / женская аудитория | без дополнительного ограничения, начальная отметка 0 |
| Подписчики | 3 000–30 000 |
| Средний охват поста | не задан |
| Средний охват поста за 24 часа | от 300, верхняя граница не задана |
| Индекс цитирования | не задан |

Все перечисленные параметры редактируются в панели. Также доступны исключение мёртвых каналов, SCAM/FAKE и красной метки. Ползунки TGStat изменяются через `ionRangeSlider.update`, после чего проверяется их фактическое состояние. Поля с пустым значением остаются незаданными. Концы шкал 120+ и 100+ не превращаются в жёсткий верхний предел.

Свойства языка, возраста, ERR/ER и ИЦ фильтруются на TGStat. Публичное превью t.me/s не подтверждает их независимо. Отношение просмотров к подписчикам, зрелость постов и частота публикаций остаются отдельными критериями аудита. «Фокус аудита» сужает специализацию уже найденных каналов и не отправляется в поиск как ключевое слово.

При типе «любой» сайт может вернуть приватные каналы без публичного username. Они учитываются в статистике `without_public_username`, но не проверяются через t.me/s. Страница только с такими каналами не останавливает чтение смешанной выдачи, если сайт даёт следующую порцию.

## Очередь, история и экспорт

Каждая тематика имеет отдельные страницу, буфер, бюджетную статистику и число подходящих кандидатов. Каналы, попавшие в несколько тематик, проверяются один раз; источники сохраняются. Исходный столбец CSV «Поисковые запросы» сохранён для прежних отчётов. Справа добавлены «Тематики TGStat» и «Фильтры поиска TGStat».

Новый поиск исключает ранее обработанные каналы по прежним правилам. Изменение фильтров применяется к новому запуску. «Продолжить сохранённый запуск» сохраняет его фильтры и очередь. Прежний поиск по словам остаётся доступен в истории и явно обозначен в панели; его продолжение не превращается в поиск по тематикам автоматически. Старые настройки восстанавливаются без подмены сегодняшними значениями возраста, языка и ERR.

## Консоль

```powershell
.\.venv\Scripts\python.exe robot_parser.py --list-categories
.\.venv\Scripts\python.exe robot_parser.py --categories 34 --count 5
.\.venv\Scripts\python.exe robot_parser.py --categories 28 33 --count 10
.\.venv\Scripts\python.exe robot_parser.py --categories 'Дизайн' --micro ux_ui_design --count 5
.\.venv\Scripts\python.exe robot_parser.py --resume
```

Прежние `--niche` и `--topic` отклоняются с подсказкой, чтобы не спутать ID внутреннего каталога с ID TGStat. Совместимый программный помощник принимает `category='34'` или `category='Дизайн'`; передача одновременно категории и ключевого слова отклоняется.

## Проверка изменения

100 модульных и интерфейсных проверок, включая значения со скриншотов, редактирование фильтров в AppTest, неверные границы, правильные ID полей, обновление вариантов, отбор до цели, продолжение очереди, дубли и страницы с приватными каналами. Проверки используют обезличенную сохранённую форму, временные базы и имитацию браузера. Живой поиск на TGStat при этом обновлении не запускался. Действие сайта после ручной проверки защиты предстоит проверить при пользовательском запуске.
