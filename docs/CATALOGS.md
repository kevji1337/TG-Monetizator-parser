# Каталоги и происхождение

Рабочие файлы находятся в `monetizer/data/`:

- `keyword_catalog.json`: 11 ниш, 52 направления, 718 запросов (число записей внутри направлений; между направлениями запросы могут пересекаться).
- `outreach_playbook.json`: 11 сценариев.
- `sources/`: исходные четыре JSON от ChatGPT и Claude, предоставленные владельцем проекта.
- `merge_report.json`: SHA-256 нормализованного JSON исходников (без зависимости от переводов строк Windows/Git), соответствия ID, сохранённые ID и термины, ожидающие проверки.

Сборка воспроизводится командой `.venv\Scripts\python.exe scripts\merge_catalogs.py`.
Все 45 прежних ID сохранены, поэтому история поисков остаётся связанной с выбранными направлениями.

Смешанные направления Claude разделены по явной карте `SPLIT` в скрипте. Например, SQL относится к AI-аналитике, а Cursor и Claude Code — к разработке. Если узкую область нельзя определить однозначно, термин остаётся только в исходнике и `pending_review`, а не попадает в рабочую выдачу автоматически. Общий английский, AI-видео, йога/пилатес и четыре новых направления получили собственные ID. Раздел азиатских языков пока объединён: для точного поиска оператор редактирует запросы или задаёт свою тему.

Термины дополняют поиск; текстовые expert_signals/non_target_signals служат редакторской подсказкой и контекстом для внешнего AI. Локальный классификатор не превращает эти описания в полноценное понимание смысла. Его качество измеряется отдельно по ручной разметке.

Формат Claude для сценариев нормализован: global_rules преобразованы в дополнительный раздел словаря, сценарии сопоставлены со стабильными ID, вымышленные примеры получили fictional=true. Исходные запреты с конкретными фразами сохранены для программной проверки; описательные запреты Claude добавлены как редакторские правила.

После изменения каталога меняется CATALOG_VERSION и область сравнения статистики запросов. Для живых данных используйте кэш и пересчёт без повторного HTTP. Сохранённые ручные сообщения не перезаписываются при обновлении каталога.
