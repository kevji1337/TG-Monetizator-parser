# Локальная Dev-версия

## Запуск

Запустите `run_monetizer_dev.bat` в папке проекта или `Запуск_Робота_TG_DEV.bat` на Рабочем столе. Обычный запуск `run_monetizer.bat` сохраняется. Это один проект с режимом диагностики и общей базой.

Навигация находится слева в **«Разделы приложения»**. Постоянная кнопка **«На главную — поиск»** возвращает к поиску, не останавливая задачу. Откройте **Dev-диагностика**: состояние задачи и браузера, последние записи лога, кнопка скачивания лога и закрытие сохранённого окна Chrome. Параметры Dev-режима доступны слева в «Режим разработки».

## Автоматическое применение правок

Оба BAT-файла и прямой запуск Streamlit из папки проекта включают отслеживание исходников и `runOnSave`. После сохранения Python-файла интерфейс обновляется автоматически. Папки отчётов, базы, браузерных профилей, логов и виртуального окружения исключены из наблюдения, чтобы запись результатов не вызывала обновления страницы.

Объект задачи и список управляемых окон Chrome хранятся на время жизни процесса отдельно от перезагружаемых модулей. Перерисовка панели не создаёт второй поиск и сохраняет кнопки остановки и продолжения. Текущая задача продолжает использовать уже загруженную логику; новая версия обработчика создаётся между задачами при следующей полной перерисовке. Для нового запуска используются сохранённые данные и настройки. Изменение зависимостей Python или параметров запуска сервера требует перезапуска.

Если панель запущена старым BAT с `fileWatcherType=none`, после завершения текущего поиска один раз закройте её через Ctrl+C и запустите BAT заново. Сам launcher при повторном открытии лишь открывает уже работающий сервер и не меняет его параметры. После этого обычные правки кода не требуют перезапуска консоли.

Полный локальный файл: `results/monetizer/logs/application.log`. Ротация: до 5 МБ, три предыдущих файла. Сообщения содержат идентификаторы задачи/браузера, этапы, длительность, HTTP/status ответа TGStat и traceback. Пароли, cookies и HTML не собираются; URL очищаются от параметров и учётных данных. Логи и драйверы исключены из Git. Кнопка «Скачать лог диагностики» отдаёт последние записи, а не всю историю ротации.

## Ошибка SSL при обновлении тематик

Старый запуск `undetected_chromedriver` заново обращался к серверам загрузки драйвера через urllib даже при наличии подходящего драйвера. Ошибка `SSL: UNEXPECTED_EOF_WHILE_READING` могла прервать этот шаг ещё до чтения категорий.

Теперь определяются установленная версия Chrome и версии локальных ChromeDriver. Совместимый драйвер копируется в `results/monetizer/drivers/` и передаётся явно: сетевой поиск версии и повторное скачивание не выполняются. Если совместимого файла нет, используется официальный HTTPS-источник Chrome for Testing с таймаутами и ограниченными повторами. Проверка TLS не отключается. При обновлении Chrome может понадобиться новое скачивание; при сетевой ошибке смотрите этап подготовки драйвера в логе.

На этой установке проверены Chrome и ChromeDriver **155.0.8059.84**; драйвер из кэша использован без скачивания.

## Почему Chrome раньше сразу закрывался

В сохранённых запусках TGStat возвращал 30 каналов, уже находившихся в базе. Затем сайт отвечал `status=restricted`; прежний код завершал задачу и закрывал Chrome в finally. Такой ответ означает ограничение доступа, а не отсутствие подходящих каналов.

При `restricted` теперь показывается ожидание ручного входа:

1. Выполните вход или проверку сайта в открытом Chrome самостоятельно.
2. Нажмите **«Продолжить после входа»** в разделе поиска или Dev-диагностики.
3. Парсер заново применит фильтры и повторит нужную страницу. Повторов после ручного входа — не более трёх за один вызов страницы.

Ожидание по умолчанию — 300 секунд; его можно изменить. При таймауте сохраняется частичный результат. Если включено «Оставлять Chrome открытым при ошибке», окно сохраняется для осмотра до явного закрытия в Dev-разделе, вручную или выхода из приложения. Успешное завершение обычно закрывает браузер. Остановка пользователем прерывает ожидание. Вход не гарантирует снятие тарифного или иного ограничения TGStat.

## Ускорение старта

- BAT проверяет наличие модулей без их повторного тяжёлого импорта.
- Health-check обращается напрямую к 127.0.0.1 без системного HTTP-прокси, имеет короткий таймаут и частый опрос готовности.
- В обычном режиме отключено наблюдение за файлами; в Dev включён poll для разработки.
- База, история, пакетный разбор и качество рассчитываются только при открытии соответствующего раздела.
- pandas и openpyxl импортируются при использовании таблиц/Excel.
- Оценки сохранённых строк повторно используются при неизменных данных, правилах, настройках, профиле отправителя и дате; база не переписывается при каждом неизменном старте.

Измерение на копии текущей базы, три отдельных процесса AppTest: до 1.014 / 0.969 / 0.998 с, после 0.812 / 0.798 / 0.789 с. Медиана загрузки страницы уменьшилась примерно на 20%. Это измерение выполнения страницы, без запуска HTTP-сервера и системного браузера.

## Что проверено

В настоящем Chrome без панели успешно прочитаны 47 тематик и первая страница из 30 каналов категории «Дизайн» с заданными фильтрами. Это подтверждает работу первой страницы и обновления списка; авторизация и дальнейшие страницы могут по-прежнему ограничиваться TGStat.

114 автоматических проверок: кэш драйвера без сети, проверяемое HTTPS-скачивание, ошибка TLS, сохранение/закрытие окна, ручное продолжение, отмена, редактирование фильтров, очередь и AppTest навигации. Для тестов `MONETIZER_LOG_DIR` направляется во временную папку, чтобы намеренно вызванные ошибки не смешивались с рабочими логами.
